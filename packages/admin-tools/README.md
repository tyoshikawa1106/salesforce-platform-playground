# Salesforce 管理者向けツール

導入したい機能を選んでください。各フォルダのZIPには、その機能のSalesforce DXソース、共通部品、Apexテスト、デプロイ対象一覧、導入手順が含まれます。

GitHubでは、各機能のREADMEからZIPを開き、**Download raw file** で保存して展開します。リポジトリをクローン済みの場合は、ルートで各機能の手順を実行し、`--manifest` にその機能の `packages/admin-tools/<フォルダ名>/package.xml` を指定します。たとえば組織エクスプローラーは `packages/admin-tools/org-explorer/package.xml` です。

| 機能                                                                      | 用途                                                                                   |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [組織エクスプローラー](./org-explorer/README.md)                          | ロール階層・上司階層をたどり、所属ユーザーを確認する。                                 |
| [オブジェクトエクスプローラー](./object-explorer/README.md)               | オブジェクト間の参照関係と項目定義を確認し、データ分類の編集とCSVの入出力を行う。      |
| [設定変更履歴エクスプローラー](./setup-audit-trail-explorer/README.md)    | 設定変更履歴を月単位で検索・分析し、CSVに出力する。                                    |
| [外部クライアントアプリ認証管理](./external-client-app-manager/README.md) | ローカル外部クライアントアプリの鍵・秘密を更新し、旧認証情報を確認・削除する。         |
| [OAuth トークン発行](./oauth-token-issuance/README.md)                    | 同じ組織のアプリを認可し、発行されたトークンとスコープを確認する。                     |
| [ユーザー作成アシスタント](./user-create-assistant/README.md)             | 既存ユーザーを参照して新規ユーザーを作成し、権限セット・グループの割り当てを引き継ぐ。 |
