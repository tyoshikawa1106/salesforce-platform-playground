# 外部クライアントアプリケーション管理ルール

## 命名

| 区分                       | 表示名                              | API 参照名                       |
| -------------------------- | ----------------------------------- | -------------------------------- |
| 外部システム連携・自動実行 | `<システム名>連携`                  | `<システム名>Integration`        |
| 外部システム連携・本人認証 | `<システム名>連携（本人認証）`      | `<システム名>IntegrationPerUser` |
| 組織内の共用 API アクセス  | `Salesforce API アクセス（組織内）` | `InternalSalesforceApi`          |
| 組織内の特定機能専用       | `<機能名>`                          | `<機能のAPI参照名>`              |

外部システム連携の名前には、個別の業務用途を含めません。API 参照名は英字で始め、英数字のみで40文字以内とします。上限を超える場合は、API 参照名のシステム名部分に略称を使います。

| 例       | 表示名                                   | API 参照名                           |
| -------- | ---------------------------------------- | ------------------------------------ |
| 自動実行 | `Herokuプレイグラウンド連携`             | `HerokuPlaygroundIntegration`        |
| 本人認証 | `Herokuプレイグラウンド連携（本人認証）` | `HerokuPlaygroundIntegrationPerUser` |

## 認証設定

| 区分                       | 設定方針                                                                                                                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 外部システム連携・自動実行 | OAuth のクライアント資格情報フローを使います。実行ユーザーに専用の連携ユーザーを指定し、連携に必要な権限を付与します。                                                                      |
| 外部システム連携・本人認証 | OAuth の認可コードフローを使い、接続元のコールバック URL を登録します。アプリの利用を許可するユーザーに、必要なアクセス権限を付与します。利用者は自分の Salesforce アカウントで認証します。 |
| 組織内の API アクセス      | 利用者が自分の Salesforce アカウントで認証し、本人の権限で同じ組織の API にアクセスします。                                                                                                 |

同じ外部システムで自動実行と本人認証の両方を使う場合は、アプリケーションを分けます。本人認証用のアプリケーションは、そのシステムの利用者間で共用します。OAuth スコープは接続に必要なものに限定します。
