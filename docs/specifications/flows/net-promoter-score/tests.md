# 推奨度アンケート（NPS）の確認手順

[機能仕様に戻る](index.md)

## 確認手順と期待結果

このFlow専用の自動テストはありません。画面の表示と回答の保存はSalesforce Surveys上で確認します。

| 操作                                                                 | 確認する結果                                                                               |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| プレビューを開く                                                     | 評価と自由記述の質問が表示され、評価の下限は0、上限は10になっている。                      |
| 招待経由で評価の下限・上限をそれぞれ選び、コメントを入力して送信する | 完了時のお礼が表示される。回答を参照すると、選んだ評価と入力したコメントが保存されている。 |
| 評価とコメントを空欄のまま完了する                                   | 任意項目のため、必須入力エラーが発生せず完了画面が表示される。                             |
| ゲスト回答が許可された招待から回答ページを開く                       | 回答者が質問を表示し、入力できる。                                                         |
