# レポートエクスポート保護判定の確認手順

[機能仕様に戻る](index.md)

## 判定条件の確認

| 操作                                        | 処理行数 | Flowの期待結果 |
| ------------------------------------------- | -------- | -------------- |
| レポートのエクスポート                      | 10,000   | 偽             |
| レポートのエクスポート                      | 10,001   | 真             |
| Excel Connectorによるレポートのエクスポート | 10,001   | 真             |
| 上記以外の操作                              | 10,001   | 偽             |

## 組織上での確認

このFlow専用の自動テストはありません。対象組織でポリシーが参照するFlowと有効なバージョンを確認し、上記の条件で追加認証が要求されるかを確認します。イベントの操作または処理行数が未設定の場合の扱いも確認対象です。リポジトリにあるFlowの状態は下書きであり、判定式の確認だけでは実際のエクスポート時の動作は確定しません。
