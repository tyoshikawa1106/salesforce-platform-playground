# 組織テスト実行スクリプトのテストコードと確認内容

[機能仕様に戻る](index.md)

## 確認する振る舞い

Node.jsテストでは、次を確認します。

- 引数指定とDefault Target Org未設定時に組織操作を開始しないこと
- 接続組織と本番環境の承認境界
- ApexとFlowで`RunLocalTests`とカバレッジを指定すること
- 組織確認、設定確認、開始、進捗照会、最終結果取得の各CLIへ2分上限を渡すこと
- Apexの並列実行オプションが有効な場合だけ注意を表示し、設定を確認できない場合もテストを止めないこと
- `707`形式以外のテストランIDを拒否すること
- 開始状況不明と構造化された開始失敗を区別すること
- 完了後の最終結果取得、監視失敗、開始中と監視中のCtrl+C、結果取得失敗時の復旧案内
- JSON応答、進捗項目、TTYと非TTYの表示

実行コマンドは次のとおりです。

```sh
node --test scripts/org-tests/test/*.node.js
```

## テストファイルと代表的なケース

| ファイル                                                                          | 確認内容                                                                                                                         |
| --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| [run-org-tests.node.js](../../../../scripts/org-tests/test/run-org-tests.node.js) | Apexの並列実行オプションが有効な場合は承認前に注意を表示する。Apexの並列実行が無効な場合は並列実行オプションの注意を表示しない。 |
| [test-progress.node.js](../../../../scripts/org-tests/test/test-progress.node.js) | Salesforce CLIの成功結果からresultを取得する。Salesforce CLIを開始できない場合は原因を含めて失敗する。                           |
| [test-runner.node.js](../../../../scripts/org-tests/test/test-runner.node.js)     | 開始処理中のCtrl+CではCLIを中断して開始状況不明を案内する。進捗照会中のCtrl+CではCLIを中断して手動の結果取得コマンドを表示する。 |
