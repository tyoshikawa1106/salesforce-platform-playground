## 確認する振る舞い

NodeテストでWindowsの引数検証を通した投入・照合、照会成功・失敗時の一時SOQL削除、不正な階層、対象外のメール・電話、未知の項目、誤った組織、取消、CLI失敗、一時ファイル削除、保存値・関係の不一致を確認します。スクラッチ組織では新規・一部不足・再実行を確認し、新規データの項目と親・上司関係、既存データの不変性、全件存在時にDMLがないことを確認します。
