## 確認する振る舞い

[Node.jsテスト](../../../../scripts/record-export/test/export-records.node.js)で指定順、最新順、ID照合、分割境界、縦型の空欄補完、横型の補完禁止、false・0・NULL・複合値、レコードタイプ条件の全検索への適用と自動限定の廃止、無効項目・不完全応答、入力・CLI診断、承認前の補完有無の表示、応答待ち・待機上限・自動再試行の禁止・スキップ・再開時の状態復元を検証対象とする。生成対象のクエリ除外、固定値と構成項目の整合、生成だけの場合の検索省略、初回のまとめ保存も対象とする。最新200件・1,300項目での個別検索削減、応答順の逆転、レコードと項目の両方の分割、200件目からの値採用、中断後の候補IDと採用元の保持も検証する。

[適応分割テスト](../../../../scripts/record-export/test/adaptive-query.node.js)では、小さなデータで再分割・順序・停止条件・Composite応答を検証する。大容量の負荷試験は通常テストに含めない。

```sh
node --test scripts/record-export/test/*.node.js
```

## テストファイルと代表的なケース

| ファイル                                                                                | 確認内容                                                                                                                           |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| [adaptive-query.node.js](../../../../scripts/record-export/test/adaptive-query.node.js) | 未知のAPIエラーでも元コードとHTTP診断を保持し、生本文は出力しない。サイズ・複雑さによる再分割後もIDと項目順で完全なCSVを生成する。 |
| [export-records.node.js](../../../../scripts/record-export/test/export-records.node.js) | BOM・CRLF・コメント・大小文字の重複を除き入力順を保持する。既定の項目設定はスクリプト配下を使い、別ファイルの明示指定も保持する。  |
