# 法人取引先の検索・ページ移動

## 概要

名前と作成日で法人取引先を絞り込み、作成日時の新しい順に表示します。

## 入力

| 条件       | 解釈                                                      |
| ---------- | --------------------------------------------------------- |
| 取引先名   | 前後空白を除いた部分一致。`%` と `_` は通常文字として検索 |
| 開始日のみ | 利用者のタイムゾーンでその日の午前零時以降                |
| 終了日のみ | 利用者のタイムゾーンで翌日の午前零時未満                  |
| 両方       | 両端の日を含む範囲                                        |
| 日付未指定 | 作成日による制限なし                                      |

条件はANDで結合します。

## 処理内容

1. 初期表示では検索せず、「検索」で取得します。
2. 作成日時の降順、同じ日時ではIDの降順に並べます。
3. 1ページは最大200件に固定します。次ページ判定用に追加一行を取得します。
4. 次ページは前ページ末尾の作成日時とIDから取得します。前ページの境界を画面内で保持し、「前へ」で再取得します。
5. ページ移動には実行済みの検索条件を使います。入力中の条件は再検索まで反映しません。
6. 未保存の変更がある場合は、再検索・ページ移動前に破棄を確認します。取消または取得失敗なら元の結果と変更を保持します。

一覧の表示項目は取引先名、所有者、業種、種別、評価、作成日時、最終更新日時、変更状態・エラーです。取引先名のリンクは標準詳細画面を別タブで開きます。

## 出力・更新対象

検索結果、現在ページ番号、次ページの有無を返します。この処理ではレコードを変更しません。

## 権限・実行条件

利用者の共有と項目参照権限を適用します。個人取引先機能が有効な組織では `IsPersonAccount = false` に限定し、未有効の組織では通常の取引先を対象にします。

レコードタイプ項目がない組織では、その項目を検索対象に含めません。選択リストは行のレコードタイプごとに取得し、未指定の行ではUI APIの既定レコードタイプを使います。取得に失敗した項目の編集は無効にします。

## エラー処理

- 開始日が終了日より後なら検索を実行しません。
- 権限不足や検索例外は画面に表示し、現在の編集内容を保持します。
- 選択肢の読込中は検索・ページ移動・保存を無効にし、別ページへの応答混入を防ぎます。

## テスト・確認観点

`AccountMassUpdateSelectorTest` で同一作成日時のページ分割、名前のワイルドカード文字、個人取引先除外を確認します。`AccountMassUpdateServiceTest` で日付境界と表示上限を確認します。LWCテストでページ移動の取消・失敗を確認します。

## 制約・注意事項

検索結果全体のスナップショットは保持しません。他の利用者の作成・削除・権限変更があると、再取得するページの内容が変わることがあります。総件数や総ページ数は表示しません。保存後も元のページ境界と次ページへの移動可否を保持します。参照できる行が減ると現在ページの表示件数が減り、その後のページ取得がゼロ件になる場合があります。

## 既知の差異・確認事項

未確認：異なるタイムゾーンとレコードタイプが混在する実画面の表示は、組織上で確認します。
