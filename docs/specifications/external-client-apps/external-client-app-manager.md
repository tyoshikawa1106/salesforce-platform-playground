# 外部クライアントアプリ認証管理

管理者が本人認証し、管理画面から外部クライアントアプリの資格情報を更新する。接続先の組織とユーザーを照合する。

## ポリシー

### アプリケーションポリシー

| 項目                 | 設定値                     |
| -------------------- | -------------------------- |
| 開始ページ           | なし                       |
| 選択済みプロファイル | システム管理者プロファイル |

### OAuth ポリシー

#### プラグインポリシー

| 項目                   | 設定値                                 |
| ---------------------- | -------------------------------------- |
| 許可されているユーザー | 管理者が承認したユーザーは事前承認済み |
| OAuth 開始 URL         | 未設定                                 |
| カスタム範囲           | なし                                   |
| Apex プラグインクラス  | 未設定（認証時に実行するカスタム処理） |

#### アプリケーション認証

| 項目                                                        | 設定値                                                 |
| ----------------------------------------------------------- | ------------------------------------------------------ |
| 更新トークンポリシー (アイドル状態の有効期間制限を適用済み) | 特定の時間使用されていない更新トークンを期限切れにする |
| 更新トークンの有効期間                                      | 30                                                     |
| 更新トークンの有効期間単位                                  | 日                                                     |
| シングルログアウトを有効化                                  | オフ                                                   |
| 高保証セッションが必要です                                  | オフ                                                   |
| カスタム属性                                                | なし                                                   |

## 設定

### 基本情報

| 項目                               | 設定値                           |
| ---------------------------------- | -------------------------------- |
| 外部クライアントアプリケーション名 | 外部クライアントアプリ認証管理   |
| API 参照名                         | ExternalClientAppManager         |
| 取引先責任者 メール                | アプリの管理連絡先               |
| 配信状態                           | ローカル                         |
| 取引先責任者 電話                  | 未設定（管理連絡先の電話番号）   |
| 情報 URL                           | 未設定（アプリの案内ページ）     |
| アイコン URL                       | 未設定（アプリのアイコン画像）   |
| ロゴ画像 URL                       | 未設定（アプリのロゴ画像）       |
| 説明                               | 外部クライアントアプリの認証管理 |

### OAuth 設定

#### アプリケーション設定

| 項目                   | 設定値                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| コールバック URL       | 外部認証 ID プロバイダー `ExternalClientAppManager` のコールバック URL                                                                |
| 選択した OAuth 範囲    | API を使用してユーザーデータを管理 (api)、いつでも要求を実行 (refresh_token, offline_access)、一意のユーザー識別子にアクセス (openid) |
| すべてのトークンを調査 | オフ                                                                                                                                  |
| ID トークンを設定      | オフ                                                                                                                                  |

#### フローの有効化

| 項目                                       | 設定値 |
| ------------------------------------------ | ------ |
| クライアントログイン情報フローを有効化     | オフ   |
| 認証コードおよびログイン情報フローを有効化 | オフ   |
| デバイスフローを有効化                     | オフ   |
| JWT ベアラーフローを有効化                 | オフ   |
| トークン交換フローを有効化                 | オフ   |

#### セキュリティ

| 項目                                                                     | 設定値 |
| ------------------------------------------------------------------------ | ------ |
| Web サーバーフローの秘密が必要                                           | オン   |
| 更新トークンフローの秘密が必要                                           | オン   |
| サポートされる認証フローに Proof Key for Code Exchange (PKCE) 拡張を要求 | オン   |
| 更新トークンのローテーションを有効化                                     | オン   |
| 指名ユーザーの JSON Web トークン (JWT) ベースのアクセストークンを発行    | オフ   |
| アイドル状態更新トークンの有効期間 (TTL) を 30 日に制限                  | オン   |
| Demonstrating Proof of Possession (DPoP) 拡張を必須にする                | オフ   |
