# サンプル連携（本人認証）の手動設定

## 外部クライアントアプリケーションを作成する

1. ［設定］→［外部クライアントアプリケーションマネージャー］で［新規外部クライアントアプリケーション］をクリックします。
2. ［外部クライアントアプリケーション名］に **サンプル連携（本人認証）**、［API 参照名］に `SampleIntegrationPerUser` を入力します。［取引先責任者 メール］には導入先の管理連絡先を入力し、配布は［ローカル］を選びます。
3. ［API (OAuth 設定の有効化)］を展開し、［OAuth を有効化］をオンにします。

| 項目                                                                     | 設定値                                                                                                        |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| コールバック URL                                                         | ローカルのサンプルでは `https://localhost/oauth/callback` を入力し、接続元のコールバック URL にも同じ値を設定 |
| 選択した OAuth 範囲                                                      | `api`、`refresh_token, offline_access`、`openid`                                                              |
| すべてのトークンを調査                                                   | オフ                                                                                                          |
| ID トークンを設定                                                        | オフ                                                                                                          |
| クライアントログイン情報フローを有効化                                   | オフ                                                                                                          |
| 認証コードおよびログイン情報フローを有効化                               | オフ                                                                                                          |
| デバイスフローを有効化                                                   | オフ                                                                                                          |
| JWT ベアラーフローを有効化                                               | オフ                                                                                                          |
| トークン交換フローを有効化                                               | オフ                                                                                                          |
| Web サーバーフローの秘密が必要                                           | オン                                                                                                          |
| 更新トークンフローの秘密が必要                                           | オン                                                                                                          |
| サポートされる認証フローに Proof Key for Code Exchange (PKCE) 拡張を要求 | オン                                                                                                          |
| 更新トークンのローテーションを有効化                                     | オン                                                                                                          |
| 指名ユーザーの JSON Web トークン (JWT) ベースのアクセストークンを発行    | オフ                                                                                                          |
| アイドル状態更新トークンの有効期間 (TTL) を 30 日に制限                  | オン                                                                                                          |
| 更新トークン IP 許可リストを適用                                         | オフ                                                                                                          |
| Demonstrating Proof of Possession (DPoP) 拡張を必須にする                | オフ                                                                                                          |

入力内容を確認し、［作成］をクリックします。

## 利用ポリシーを設定する

1. マネージャーで［サンプル連携（本人認証）］を開き、［ポリシー］を編集します。
2. ［OAuth ポリシー］で次の値を設定します。

| 項目                          | 設定値                                                 |
| ----------------------------- | ------------------------------------------------------ |
| 許可されているユーザー        | 管理者が承認したユーザーは事前承認済み                 |
| 更新トークンポリシー          | 特定の時間使用されていない更新トークンを期限切れにする |
| 更新トークンの有効期間 / 単位 | 30 / 日                                                |
| IP 制限の緩和                 | IP 制限を適用                                          |

アプリの利用を許可するプロファイルに、標準の［システム管理者］を追加して保存します。

## 接続元に登録して確認する

1. アプリの［設定］→［OAuth 設定］→［コンシューマー鍵と秘密］を開き、求められた本人確認を完了します。
2. 接続元の資格情報設定に、コンシューマー鍵をクライアント ID として、コンシューマーの秘密をクライアントシークレットとして登録します。
3. 接続元から利用者本人で OAuth 認証し、登録したコールバック URL に戻って接続が完了することを確認します。
